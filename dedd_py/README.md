# 数字化美学牙科分析与设计（Python 版）

参考开源项目 [kqstone/Digital-Esthetic-Dentistry-Design](https://github.com/kqstone/Digital-Esthetic-Dentistry-Design)
（Java 版，依赖后端服务器）的框架，用 **Python + PySide6** 重新实现，
**纯本地运行，无需 Java、无需网络**。

## 运行环境

- Windows 10/11
- Python 3.10+（本机已验证 3.14）
- 依赖：PySide6、opencv-python、numpy、Pillow

## 安装与启动

```bat
:: 1. 安装依赖（只需一次）
python -m pip install -r requirements.txt

:: 2. 启动
python main.py
```

也可以直接双击 `启动程序.bat`。

> 提示：Windows 未启用长路径支持时，`PySide6` 完整包可能安装失败，
> 请使用精简包 `PySide6-Essentials`（本程序只用 Qt 核心模块，无需 QML/WebEngine）。
> 若 `opencv-python` 安装失败，请先执行 `python -m pip install numpy` 再重试。

## 使用流程（六步，与顶部标签一致）

> **第一次用**：启动后是引导页，点「新建项目 / 打开已有工程 / 打开示例工程」直接开始，不再是空白界面。
> **想少点几下**：载入两张照片后点工具栏最左边的「**一键完成**」——自动 AI 检测两视图牙位 →
> 跳到「美学设计」→ 自动优化；之后只需微调即可导出。

| 步骤 | 标签 | 操作 |
|---|---|---|
| 1 | 编辑照片 | 新建项目 → 双击左视图载入正面照、双击右视图载入口内照（也可旋转 90°） |
| 2 | 平行合平面 | 左右视图联动观察，检查咬合平面 |
| 3 | 标记唇线 | 在正面视图上左键单击加点，点回起点闭合；右键删点 |
| 4 | 标记牙位 | 在图上拖拽画框，为每颗牙填写**牙位**（11/12/13/21/22/23）和**冠长(mm)**（口内视图） |
| 5 | 美学设计 | 拖动/缩放牙齿框，右键拖动调**亮度/黄度**，右键单击切换 轮廓/牙冠/隐藏 模式；可"自动优化" |
| 6 | 导出设计 | 查看设计图示、口内前后对比、正面前后对比，保存 JPG |

### 鼠标操作

| 操作 | 功能 |
|---|---|
| 左键拖拽 | 标记牙位：画框/移动/八方向缩放；美学设计：调整牙齿 |
| 右键 | 标记牙位：删除矩形；美学设计：单击切显示模式、拖动调亮度黄度 |
| 中键拖拽 | 平移视图 |
| 滚轮 | 缩放视图 |

### 键盘操作（美学设计 / 标记牙位）

| 操作 | 功能 |
|---|---|
| 单击牙框 | 选中（橙色虚线高亮，状态栏显示 x/y、宽×高、冠长、**宽长比**） |
| `Tab` / `Esc` | 循环选中下一颗 / 取消选中 |
| `←` `↑` `→` `↓` | 微移选中牙 1 px（按住 `Shift` = 10 px） |
| `[` `]` | 以中心为准收窄 / 加宽 |
| `-` `=` | 以中心为准减高 / 增高 |
| `Shift` + 拖拽角落 | 等比缩放（锚定对角不跑位） |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（覆盖标记、拖动、缩放、亮度黄度、显示模式、自动优化） |

> 拖动亮度黄度时鼠标松开才记一次撤销，不会一帧一堆历史；牙框最小 4 px，拖不成一条线找不回来。

## 项目文件

- `.deddp`：本程序工程文件（zip：`project.json` + 两张照片），菜单"文件→保存/读取"
- 兼容导入原版 `.depx`：菜单"文件→导入原版工程(.depx)"，自动解析原版 XML 数据

## 功能说明与限制

- **自动优化**（口内）：统一冠长 + 按美学宽长比（11/21≈0.80，12/22≈0.75，13/23≈0.70）调整牙冠高度
- **自动对齐**（正面）：中切牙中线对中 + 左右对称化 + 微笑曲线
- **人脸分析**：本地 OpenCV 检测人脸/眼睛，自动旋转眼线至水平并裁剪（替代原版网络 API）
- **AI 检测**：本地启发式，按嘴部区域自动生成 6 颗前牙框（供参考，需手动微调）；口内视图请手动标记
- 牙齿模板：前牙 6 颗（11-13、21-23）的轮廓/牙冠图，来自原仓库资源（21/22/23 由 11/12/13 镜像生成）
- 亮度/黄度算法与原版一致：R/G/B 分别 `+b+y / +b+y / +b-2y`
